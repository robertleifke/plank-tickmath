# TickMath in Plank 

`TickMath.sol` is a solidity library used in [Uniswap v3](https://github.com/Uniswap/v3-core) to convert between discrete price ticks and fixed point square root price representations. But solidity lacks rich type systems and compiler optimization for math heavy code, so implementing functions like price to tick conversions and and vice versa requires handcrafted constants and bit tests to approximate exponentials.
